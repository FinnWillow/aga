  # AGA: roadmap

  Rule: build systems in the order the vertical slice needs them.
  The slice (end of Phase 2) proves the game is fun before anything else gets built.
  Effort: S = days, M = 1–2 weeks, L = several weeks.
  [x] done · [ ] *partial* · [ ] not started

  ## Phase 0: decisions
  - [x] Move speed: 2 px/frame (4 for testing)
  - [x] Screen: 4:3, view 320×240 (the room view), zoom in pixels
  - [x] Colour: art drawn in 4 grey "slots" (0/85/170/255), coloured in game by palettes; slots ordered dark to light in every palette
  - [x] Elevation: levels 0–6, objects draw over their own level and the next one up
  - [x] No real hidden passages; fake them with cover layers / triggers when needed
  - [x] Inventory model: weapons/tools are unlocks; stackable items one slot each (~99); small inventory
  - [x] Combat: careful, souls-style dodge and punish; guns main, melee for distance / finishers; recklessness punished, exploring and
  fighting rewarded
  - [x] Loot: Skyblock-style rare drops (gear or crafting materials); ways to raise odds / narrow drops; no levelling system
  - [x] Crafting: commissions at traders (items + money + the right trader + time), no separate crafting system; weapon upgrades too
  (the weapon is handed over until done)
  - [x] Needs: no hunger. Health, stamina (dodging and attacking) and exhaustion (abilities) bars; food restores them, eaten from a
  non-pausing inventory
  - [x] Spores: why food heals and why Frost can use abilities (plant-monster organs); see the brief
  - [x] Time: in-game clock, day/night, sleep skips time; timed quests fail on not showing up; some NPCs keep schedules; off-screen
  events resolved when checked, not simulated
  - [x] Structure: nothing required, no essential NPCs; deity reachable from the start; reason route needs understanding; killing NPCs
  changes Frost's reactions, the world's reaction and the ending
  - [x] Abilities: permanent and toggleable, unlocked by eating organs; run on exhaustion, refilled by food; temporary boosts from items
  - [x] World reaction to kills: prices up, quests closed, attacked, treated as a plant monster; UNDERTALE-style genocide around humans
  - [x] Opening: the village attack stays as the scripted start

  ## Phase 1: foundation
  - [x] Movement: diagonals at full speed per axis (2.83; normalized can't sit on the pixel grid), facing kept while valid, animation from
  actual movement
  - [x] Tile collision: generated from tileset_collisions.png (masks + debug outlines), per level (own level + the one above), corner correction /
  diagonal sliding, unstuck safety net, feet-sized masks
  - [x] Palette system: palette shader, per-object (obj_palletted) and per-layer (from layer name)
  - [x] Depth: y-sorting with depth bands per level
  - [x] Ramps: level decided by position on the ramp
  - [x] Input layer: named actions in global.keymap (keyboard, mouse, wheel); rebinding menu in Phase 3
  - [x] Camera: follow, look-ahead, zoom (in pixels), cursor lean, screen shake; persistent, sets up views in every room
  - [x] Pixel-perfect rendering + scaling: native-res surface, integer window scaling, smooth sub-pixel camera
  - [x] Game states: playing / paused / menu / inventory / journal / dead (S)
  - [x] Debug tools: debug menu (F1) with per-object registration, palette editor, rm_sandbox, collision outlines. Spawn keys, god mode,
  hitbox view, give-item keys come with Phase 2
  - [x] Stats: health / stamina / exhaustion as one reusable component for the player and enemies (drain, max; only
  stamina regenerates) (S)
  - [ ] Dodge / dash: costs stamina, i-frames, can't be spammed (S)
  - [ ] Game clock: in-game time, day/night tint, skip-to hook for sleeping, day length as a debug slider (S)

  ## Conventions (keep these consistent)
  - Tile layer names: `<palette>_<anything>_l<level>`
    - first word = palette name (from scr_pallettes); `index` = no palette (shadows)
    - last word = level (`l0`…`l6`); no suffix = level 0
  - Collision: white in tileset_collisions.png = solid, same grid as tileset.png;
    don't mirror/rotate tiles that have collision
  - Sorting objects inherit obj_sorted (draw_level = level they stand on);
    palette objects inherit obj_palletted
  - Rooms: no views or camera needed in the room editor; obj_global goes only in the first room
  - Debug: register editable fields at the end of Create with debug_target / debug_add
