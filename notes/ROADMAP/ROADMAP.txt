  # AGA: roadmap

  Rule: build systems in the order the vertical slice needs them.
  The slice (end of Phase 2) proves the game is fun before anything else gets built.
  Effort: S = days, M = 1–2 weeks, L = several weeks.
  [x] done · [ ] *partial* · [ ] not started

  ## Phase 0: decisions
  - [x] Move speed: 2 px/frame (4 for testing)
  - [x] Screen: 4:3, view 640×480 at zoom 1.0
  - [x] Colour: art drawn in 4 grey "slots" (0/85/170/255), coloured in game by palettes; slots ordered dark to light in every palette
  - [x] Elevation: levels 0–6, objects draw over their own level and the next one up
  - [x] No real hidden passages; fake them with cover layers / triggers when needed
  - [x] Inventory model: weapons/tools are unlocks; stackable items one slot each (~99); small inventory
  - [ ] Scarcity split: which resources are scarce (supplies, materials) vs generous (combat drops)
  - [ ] Killable NPCs: essential NPCs, or a "quest-giver dead" outcome for every quest
  - [ ] Event clock: real time, in-game days, or per-quest timers
  - [ ] Survival needs: hunger / other needs, or food only as healing / trade goods

  ## Conventions (keep these consistent)
  - Tile layer names: `<palette>_<anything>_l<level>`
    - first word = palette name (from scr_pallettes); `index` = no palette (shadows)
    - last word = level (`l0`…`l6`); no suffix = level 0
  - Collision: white in tileset_collisions.png = solid, same grid as tileset.png;
    don't mirror/rotate tiles that have collision
  - Sorting objects inherit obj_sorted (draw_level = level they stand on);
    palette objects inherit obj_palletted
